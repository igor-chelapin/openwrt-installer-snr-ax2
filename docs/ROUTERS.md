# Какие роутеры подходят

## Прошивка программой OpenWrt Installer

Только **SNR-CPE-AX2**. Для других моделей прошивка программой не предусмотрена — их ставят на OpenWrt по инструкции для конкретной модели (https://firmware-selector.openwrt.org), а дальше управляют панелью управления.

## Управление панелью управления (VPN xray, подписки, zapret, DNS, Wi-Fi)

Подходит любой роутер, на котором **уже стоит OpenWrt 23.05+** и хватает памяти на xray с geo-базами: **от 256 МБ ОЗУ и 128 МБ флеш**.

Недорогие модели (ориентир 2–4 тыс. ₽, цены сильно зависят от магазина и купонов), которые OpenWrt поддерживает и на которых хватает памяти:

| Модель | Чип | Как ставится OpenWrt | Обратите внимание |
|---|---|---|---|
| **SNR-CPE-AX2** | MT7981 | этой программой | — |
| **Xiaomi AX3000T** | MT7981 | по инструкции OpenWrt Wiki (обычно через xmir-patcher) | подходят не все ревизии/партии — сверяйтесь с OpenWrt Wiki |
| **Cudy WR3000 / WR3000S / WR3000E / WR3000P** | MT7981 | промежуточный образ Cudy через веб-интерфейс → sysupgrade | у каждой модели и ревизии свой образ; некоторые — только в snapshot |
| **Netis NX31** | MT7981 | по инструкции OpenWrt для модели | — |
| **WBR3000UAX** (бренд Wildberries) | MT7981 | — | по отзывам аналог AX3000T с USB; проверьте поддержку в Firmware Selector |

Не подходят для xray: роутеры с 16–32 МБ флеш и 64–128 МБ ОЗУ (Xiaomi 4A Gigabit, старые TP-Link, Netgear WNDR3800 и т. п.) — VPN с geo-базами туда не влезет.

> Список составлен по открытым источникам, на этих моделях панель управления не проверялся. Перед покупкой проверьте модель и ревизию в [Firmware Selector](https://firmware-selector.openwrt.org) и [Table of Hardware](https://openwrt.org/toh/start).
