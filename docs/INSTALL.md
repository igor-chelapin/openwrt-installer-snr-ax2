# Установка и первая настройка

## Что понадобится

- Роутер **SNR-CPE-AX2** (заводская прошивка или уже OpenWrt).
- Компьютер с Ethernet-портом (или USB-Ethernet переходником) и кабель.
- Windows 7 SP1+ / Linux / macOS.
- Для VPN — ключ `vless://…` или ссылка на подписку от вашего VPN-сервиса.

## Порядок

1. Скачайте из [Releases](../../../releases) установщик `Setup.exe` (Windows) или архив с программой — прошивка уже внутри.
2. Кабель: компьютер ↔ любой **LAN**-порт роутера. Кабель провайдера — в **WAN**.
3. Запустите программу (Windows — от администратора, Linux/macOS — через `sudo` для прошивки).
4. Откроется **мастер настройки**:

| Шаг | Что происходит |
|---|---|
| Проверка роутера | Программа определяет, что стоит на роутере. Если уже OpenWrt — бэкап и прошивка пропускаются. |
| Бэкап | Все разделы флеш-памяти (включая Factory — калибровку Wi-Fi) сохраняются в папку `backup_*`. **Сохраните её на флешку/в облако.** |
| Прошивка | IP компьютера → `192.168.1.254`, запись загрузчика, загрузка recovery по TFTP, установка основной прошивки. 10–15 минут. **Не выключайте питание!** |
| Интернет | PPPoE (логин/пароль из договора) или DHCP. |
| Wi-Fi | Имя и пароль сети. |
| Пароль роутера | Пароль root для SSH и веб-панели. |
| Ключ VPN | vless-ссылка или подписка (можно принять с телефона или отсканировать QR). |
| Режим и DNS | 1 — только zapret, 2 — только VPN, 3 — zapret + VPN; режим DNS. |
| Проверка | Сводка: интернет, VPN-сервер, YouTube, Telegram, DNS. |

Мастер можно закрыть в любой момент и открыть снова кнопкой **«✨ Мастер настройки»** в шапке.

## Ручная прошивка (если что-то пошло не так)

То же, что делает программа, вручную:

1. IP компьютера `192.168.1.254/24`, TFTP-сервер (например, tftpd64) раздаёт `openwrt-…-initramfs-recovery.itb` под именем, которое запрашивает U-Boot.
2. Загрузчик на заводской прошивке:
   ```sh
   scp -O openwrt-mediatek-filogic-snr_snr-cpe-ax2-bl31-uboot.fip Admin@192.168.1.1:/tmp/
   ssh Admin@192.168.1.1
   mtd -e FIP write /tmp/openwrt-mediatek-filogic-snr_snr-cpe-ax2-bl31-uboot.fip FIP
   mtd erase ubi
   reboot
   ```
3. U-Boot не найдёт системы и загрузит recovery по TFTP (1–3 минуты). Откройте `http://192.168.1.1` → System → Backup/Flash firmware → **Flash image** → файл `…squashfs-sysupgrade.itb`, **снимите галочку «Keep settings»** → Continue.
4. Через 3–5 минут роутер загрузится в OpenWrt: `192.168.1.1`, логин `root` без пароля.

Если recovery уже загружен, а основная прошивка не встала — в программе есть кнопка **«Дошить (recovery уже загружен)»** в разделе «Прошивка и бэкап».

## Возврат заводской прошивки

Раздел «Прошивка и бэкап» → **«Восстановить из бэкапа»** → выберите папку `backup_*`. Программа запишет обратно разделы `ubi`, `u-boot-env` и `FIP`. Нужен бэкап, сделанный этой программой **до** прошивки.
