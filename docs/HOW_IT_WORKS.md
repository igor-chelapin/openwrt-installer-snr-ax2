# Как это устроено

Программа — один файл `openwrt_installer.py` (Python 3.7+, tkinter, paramiko). Компьютер управляет роутером по SSH; на роутере не остаётся «агентов» — только конфиги и маленькие shell/ucode-скрипты.

## Прошивка

1. Компьютер получает IP `192.168.1.254`, поднимается встроенный TFTP-сервер (порт 69).
2. По SSH на заводскую прошивку загружается `bl31-uboot.fip`, пишется в раздел `FIP`, раздел `ubi` стирается, роутер перезагружается.
3. Новый U-Boot не находит систему и забирает recovery-образ по TFTP.
4. По SSH в recovery загружается sysupgrade-образ и выполняется `sysupgrade -n`.

Бэкап: `cat /dev/mtdN | gzip` для каждого раздела + MD5. Восстановление: стирание `ubi` → recovery по TFTP → `mtd write` разделов `ubi`, `u-boot-env`, `FIP` (загрузчик — строго последним).

## VPN на роутере (`/etc/xray-vpn`)

| Файл | Назначение |
|---|---|
| `base.json` | входы xray: прозрачный прокси (dokodemo-door, порт 12345), socks для проверок (127.0.0.1:10808), DNS через туннель (127.0.0.1:5353) |
| `outbound.json` | текущий сервер; `servers/NN.json` + `NN.name` — все серверы подписки, `current` — номер текущего |
| `routing.json` | правила (копия `routing-main.json` или `routing-ytvpn.json` — запасной вариант режима 3) |
| `rules.nft` | таблица `inet xray`: весь TCP из `br-lan` (кроме локальных адресов и портов торрентов) → xray; QUIC к внешним адресам отклоняется, чтобы браузер ушёл на TCP |
| `watchdog.sh` | cron: падение сервера → самый быстрый из остальных; медленный сервер → быстрый; YouTube zapret ↔ VPN |
| `sub-update.uc` | ucode-скрипт: скачивает подписку, разбирает vless-ссылки (так же, как программа), проверяет xray и меняет серверы |
| `geo-update.sh` | обновление geoip/geosite (v2fly) с проверкой xray перед заменой |
| `exclude.names` | исключённые серверы |

Служба — `/etc/init.d/xray-vpn` (procd).

## DNS (`/etc/dnsctl`)

`dnsctl.sh` выставляет dnsmasq по режиму: `127.0.0.1#5353` (через VPN), `127.0.0.1#5053` (https-dns-proxy, DoH) или DNS провайдера. Устройства с «зашитым» DNS перенаправляются на роутер (таблица `inet dnsctl`). Адреса VPN-серверов резолвятся напрямую, чтобы туннель мог подняться.

## Zapret

Пакеты [remittor/zapret-openwrt](https://github.com/remittor/zapret-openwrt) скачиваются компьютером с GitHub и ставятся на роутер. Автоподбор: `blockcheck.sh` (режим GET, проверка картинки с серверов YouTube), затем каждая найденная и 8 запасных стратегий проверяются на реальном трафике; результат пишется в `NFQWS_OPT` с профилями по доменам.
