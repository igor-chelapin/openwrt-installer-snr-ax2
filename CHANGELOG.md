# Изменения

## 1.4.0

- Один файл: прошивка OpenWrt встроена в программу — exe можно просто переслать, без архива и папки `firmware`.
- Установщик для Windows (`Setup.exe`): ярлыки в «Пуске» и на рабочем столе, удаление через «Приложения»; при удалении спрашивает, стирать ли настройки и бэкапы (по умолчанию — нет).
- Настройки, журналы и бэкапы больше не мусорят рядом с exe — они в папке данных пользователя (`%LOCALAPPDATA%\OpenWrtInstaller`); старые файлы переносятся автоматически. Кнопка «Папка данных». Переносной режим — файл `portable.txt` рядом с программой.
- Облегчённая версия называется просто «Панель управления» (OpenWrt Panel).
- Установка через `git clone`: `run.bat` (Windows) и `run.sh` (Linux/macOS) сами ставят зависимости и запускают программу.
- Самопроверка сборки `--selftest` (встроенные прошивки и их SHA256); релизы на GitHub для Windows 7–11, Linux и macOS, плюс архив со всеми файлами проекта.

## 1.3.0

- Новый интерфейс: вместо 9 вкладок — боковое меню из 5 разделов (Главная, Обход блокировок, Интернет/Wi-Fi/DNS, Роутер и компоненты, Прошивка и бэкап), прокрутка страниц, сворачиваемые блоки для редких настроек.
- «Обход блокировок» в одном месте: VPN (встроенный / Forkop / выключен) + галочка zapret + одна кнопка «Применить» вместо режимов 1/2/3; там же ключ, подписка, настройки VPN и стратегия zapret.
- Можно полностью выключить обход (всё напрямую).

## 1.2.0

- Вкладка «Компоненты»: проверка, что стоит на роутере (встроенный VPN, Forkop, zapret, зашифрованный DNS, русский язык), установка и удаление каждого компонента одной кнопкой, выбор движка VPN.
- Мастер настройки: новый шаг «Что установить на роутер» — проверяет установленное и ставит выбранное (xray или Forkop, zapret, DoH).
- Zapret: своя стратегия вручную (показать текущую / применить, с автоматическим откатом при ошибке); автоподбор и ручная стратегия работают и с Forkop (пишутся в его раздел zapret, Discord при необходимости — в отдельный раздел).

## 1.1.0

- Forkop: установка одной кнопкой (официальный установщик, без вопросов), автоматическая настройка разделов «YouTube и Discord через zapret» и «VPN: заблокированное в РФ» с вашим ключом или подпиской, sing-box extended для XHTTP, выключение и (по желанию) удаление встроенного xray для освобождения места, кнопки «Открыть панель Forkop» и «Вернуть встроенный VPN».
- Выбор движка: встроенный VPN (xray) или Forkop — учитывается кнопкой «Применить режим» и мастером.
- Строка Forkop на вкладке «Состояние».

## 1.0.0 — первая открытая версия

- Прошивка SNR-CPE-AX2 на OpenWrt 25.12.4 со встроенным TFTP, бэкап и восстановление заводской прошивки.
- Мастер первой настройки.
- VPN на xray: vless-ссылки и подписки, приём с телефона, QR камерой, выбор сервера с замером задержки, исключение серверов.
- Роутер сам: переключение при падении и при медленном сервере, обновление подписки (6 ч), обновление geo-баз (неделя).
- Zapret: установка и автоподбор стратегии; режим «zapret + VPN» с автоматическим запасным вариантом.
- DNS: DoH / через VPN / провайдера, проверка подмены.
- Панель управления — версия только для управления любым роутером на OpenWrt.
- Сборки для Windows 7–11, Linux и macOS.
